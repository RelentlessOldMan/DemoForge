# Narration for the presentation's own cards

These blocks are spoken over the cards the whole presentation opens with: the title,
the about cards (one per `intro:` block, each showing what is said), the contents and
the first chapter card. Every demo's own narration lives in its folder.

## title

Claude Demo Kit: Claude doing real engineering work.

## intro:What this is

This video holds ten short demonstrations of Claude working as an engineer. Each one
starts with a task like one a team would hand a colleague: write code to a
specification, make it faster, move it to another language, chase down a failure,
review a spreadsheet, analyse a dataset, check work against its requirements. All ten
share one project, a filter that tracks moving objects, so each demo builds on the
last. These ten were picked because they're interesting to watch, not because they're
the limit. They're a small slice of what Claude can do.

## intro:How it was made

Every demo is a real recorded session. A second Claude session plays the engineer who
asked for the work, and replies the way they would: answering questions, and pushing
back when something isn't right. What you see is replayed from that record. Long waits
are shortened, but nothing is added. After each session, the results were checked
independently, with tests Claude never saw.
